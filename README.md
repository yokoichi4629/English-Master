# English Master

「英語を見て覚えるだけではなく、英語を聞いて理解し、自分でも話せるようになるアプリ」

旅行英語・日常英会話を1日10〜15分で学ぶ、スマートフォン向けの無料Webアプリです。Cloudflare Workers(静的ファイル配信)で動きます。

## 第1段階でできること

- **ホーム**:今日の目標(20問)と進捗、連続学習日数、復習する問題、学習カテゴリー
- **4つのカテゴリー**:旅行英語(7シーン)、日常英会話(7シーン)、英単語暗記(5分類)、短文反復練習(3分類)
- **フレーズ一覧**:英文・日本語訳・音声再生・3回くり返し再生・再生速度(ゆっくり/ふつう/ナチュラル)・日本語を隠すモード・単語のお気に入り
- **意味当てクイズ**:英語を聞いて4択で意味を選ぶ。正解・不正解と解説を表示し、まちがえた問題はその回の最後にもう一度出題
- **学習記録**:学習日数、連続日数、正解率、覚えた単語・フレーズ数、この7日間のグラフ、苦手な問題

音声は端末の読み上げ機能を使うので、音声ファイルの用意や費用はかかりません。学習記録は端末内(ブラウザ)に保存されます。

## 第2段階でできること

- **発音練習**:お手本を聞く → マイクで録音(最大8秒)→ お手本と自分の声を続けて聞いてくらべる → 「言えた/もう少し/むずかしい」で自己評価。クイズの解説画面からもその場で録音できます。録音はスマホの中だけで再生し、どこにも送信・保存しません
- **翌日・3日後・7日後の復習**:まちがえた問題は翌日に復習として出題。正解するたびに3日後、7日後と間隔が広がり、すべて正解すると卒業します
- **マイリスト**:フレーズや単語の ☆ で自分だけの復習リストを作成。「むずかしい」と評価した発音も自動で追加
- **学習記録・履歴**:学習時間、復習の予定(今日/明日/7日以内)、カテゴリー別の正解率、日ごとの学習履歴(問題数・正解率・時間・発音回数)

## 第3段階でできること

- **AI発音チェック**:録音した英語をAI(Whisper)が文字に起こし、お手本と比べて100点満点で採点。聞き取れなかった単語を赤で表示し、タップでその単語だけ聞ける。50点未満のフレーズはマイリストに自動追加
- **AI英会話**:ホテル・レストラン・入国審査・買い物・道案内・雑談の6場面で、AI(Gemma 4)と英語でやりとり。声でも入力でき、不自然な英語には自然な言い方と日本語の説明、次に言えそうな返事の例を表示
- **レベルの自動調整**:直近20問の正解率が85%以上でレベルアップ、55%未満でダウン(初級・初中級・中級)。「今日の10問」の出題、選択肢の数(初級は3択)、AI英会話の英語のむずかしさが変わる
- **オフライン学習**:一度開けばアプリ本体と学習データが端末に保存され、電波がなくてもクイズ・フレーズ・復習・録音が使える(AI機能を除く)

AI機能は Cloudflare Workers AI の無料枠(1日10,000 Neurons)の範囲で動きます。目安は発音チェック1回あたり約6、AI英会話1往復あたり約10 Neurons。Workers の無料プランでは、無料枠を超えると料金が発生する代わりにその日はAI機能がエラーになります。

## 英語の音声について

- Android などは端末の読み上げ機能で再生します。
- iPhone は端末の読み上げが消音モードで鳴らないことがあるため、AI音声(Deepgram Aura)で作ったMP3を再生します。一度作った音声はサーバー(KV)と端末の両方に保存し、同じ英文は二度と作り直しません。
- 「学習記録」画面の「英語の音声」で、自動 / AI音声 / 端末の音声 を切り替えられます。

## ファイル構成

```
src/
  index.js     サーバー(AIへの中継)
public/
  index.html   画面の土台
  sw.js        オフライン用の保存処理
  style.css    デザイン
  app.js       画面と機能
  data.js      学習データ(フレーズ・単語・短文)
  manifest.webmanifest, icon*  ホーム画面に追加したときのアイコン
wrangler.jsonc Cloudflareの設定
```

## 学習データの追加

`public/data.js` の各リストに `['英語', '日本語', '補足(任意)']` を追加します。学習記録は並び順で管理しているので、**必ずリストの末尾に追加**してください。

## 手元で動かす

```bash
npm install
npm run dev
```

## 公開(Cloudflare)

Cloudflareダッシュボードの「Workers & Pages」→「作成」→「リポジトリをインポート」でこのリポジトリを選ぶと、`main` にpushするたびに自動で公開されます。手元から公開する場合は `npm run deploy`。
