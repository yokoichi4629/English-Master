# English Master 開発記録

最終更新: 2026年11月9日(バージョン 3.4)

## 1. いまの状態(ひとことで)

第1〜第3段階の機能が完成し、公開済み。Android・iPhoneの両方で動作確認済み。
次は「学習データを増やす」か「第4段階(データのバックアップ)」のどちらかから再開する予定。

## 2. 基本情報

| 項目 | 内容 |
| --- | --- |
| アプリ名 | English Master |
| 目的 | 旅行英語・日常英会話の習得(初心者〜中級者、1日10〜15分) |
| 方針 | 聞く・理解する・発音する・繰り返す。無料で使えること |
| GitHub | `yokoichi4629/English-Master`(`main` ブランチ) |
| 公開先 | Cloudflare Workers の `english-master`(URLは `english-master.<アカウント名>.workers.dev`。ダッシュボードの「Workers & Pages」で確認できる) |
| 公開のしかた | `main` に push すると Cloudflare が自動で公開(Workers Builds) |
| 使い方 | スマホのブラウザで開き、「ホーム画面に追加」でアプリのように使う |

## 3. 完成した機能

### 第1段階:基本機能
- ホーム(今日の目標20問・進捗・連続学習日数)
- 4カテゴリー:旅行英語(7シーン)、日常英会話(7シーン)、英単語暗記(5分類)、短文反復練習(3分類)
- フレーズ一覧:英文・日本語訳・音声再生・3回くり返し・再生速度(ゆっくり/ふつう/ナチュラル)・日本語を隠す
- 意味当てクイズ:英語を聞いて選ぶ。まちがえた問題はその回の最後に再出題

### 第2段階:学習機能
- 発音練習:お手本 → 録音(最大8秒)→ 自分の声 → くらべて聞く → 自己評価
- 復習:まちがえた問題を「翌日 → 3日後 → 7日後」に出題し、全部正解で卒業
- マイリスト:☆で自分だけの復習リスト
- 学習記録・履歴:学習時間、復習の予定、カテゴリー別正解率、日ごとの履歴

### 第3段階:発展機能
- AI発音チェック:録音をAIが文字起こしし、お手本と比べて100点満点で採点。聞き取れなかった単語を赤く表示
- AI英会話:6場面(ホテル・レストラン・入国審査・買い物・道案内・雑談)。声でも入力でき、自然な言い方の提案と返事の例を表示
- レベル自動調整:直近20問の正解率85%以上でアップ、55%未満でダウン(初級/初中級/中級)。出題・選択肢の数・AIの英語のむずかしさが変わる
- オフライン学習:一度開けば電波がなくてもAI以外の機能が使える

### その後の修正
- iPhoneで音が出ない問題を解決:iPhoneではAI音声(MP3)で再生するように変更。消音モードでも鳴る
- 「学習記録」画面に「英語の音声」(自動/AI音声/端末の音声)とテスト再生を追加
- アプリの更新が次に開いたときに自動で反映されるように変更。「学習記録」画面の一番下にバージョンを表示
- AI英会話に「AIの英文を隠す(聞き取り練習)」の切り替えを追加。隠しているあいだも音声はふつうに流れ、英文はタップすると表示される。設定は次に開いたときも残る。隠しているあいだは「返事の例」も隠し、「返事の例を見る」を押すと表示される(自分の入力文・より自然な言い方は隠さない)

## 4. 収録データ(目標との比較)

| 種類 | 現在 | 目標 |
| --- | --- | --- |
| 旅行英語 | 51フレーズ | 500フレーズ |
| 日常英会話 | 44フレーズ | 500フレーズ |
| 英単語 | 60語 | 1,000語 |
| 重要短文 | 22文 | 500文 |

データは `public/data.js` に入っている。**項目は必ず各リストの末尾に追加する**(途中に入れると学習記録の対応がずれる)。

## 5. 使っているサービスと料金

すべて Cloudflare の無料枠で運用中。無料プランでは上限を超えても料金は発生せず、その日はAI機能が止まるだけ。

| 用途 | サービス | 目安 |
| --- | --- | --- |
| 画面の配信 | Workers 静的ファイル | 無料・無制限 |
| AI発音チェック・声の入力 | Workers AI `@cf/openai/whisper-large-v3-turbo` | 1回 約6 Neurons |
| AI英会話 | Workers AI `@cf/google/gemma-4-26b-a4b-it` | 1往復 約10 Neurons |
| iPhoneの英語音声 | Workers AI `@cf/deepgram/aura-1`(声: asteria) | 1文 約30〜40 Neurons。作った音声は保存して再利用 |
| 音声の保存先 | KV `english-master-tts-cache`(ID: `b457379bf84e41b0ab694807b4527af0`) | 書き込み1日1,000回まで無料 |

Workers AI の無料枠は1日10,000 Neurons(日本時間の朝9時にリセット)。

```
                    /api/transcribe 文字起こし / /api/chat AI英会話 / /api/tts 英語音声

```

## 7. 学習記録の保存場所(大事)

学習記録(正解数・復習予定・マイリスト・レベルなど)は**スマホのブラウザの中だけ**に保存されている(localStorage の `english-master.v1`)。
そのため、機種変更・ブラウザのデータ削除・別の端末では引き継がれない。これを解決するのが第4段階の予定。
